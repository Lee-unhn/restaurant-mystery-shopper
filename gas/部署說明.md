# GAS 後端部署說明（附件上傳版）

前端已改為隨「送出」夾帶附件（發票／出餐照／環境照／錄音，base64）。要讓附件落地到 Drive、連結寫進 Sheet，後端 Apps Script 必須更新成 `Code.gs` 這一版。**沿用原本的 Web App 網址，前端不用改。**

## 步驟（約 3 分鐘）

1. 開啟回收用的 Google 試算表 → 擴充功能 → **Apps Script**。
2. 用本資料夾的 `Code.gs` 內容**整份取代**原本的程式碼。
   - 若你的 Apps Script 是獨立腳本（不是從試算表開的），把 `SHEET_ID` 填上試算表網址中 `/d/` 與 `/edit` 之間那串 ID。
3. 右上「部署」→「**管理部署作業**」→ 鉛筆編輯 → 版本選「**新版本**」→ 部署。
   - 執行身分：**我**；具有存取權的使用者：**任何人**（維持原設定）。
   - ⚠️ 一定要走「管理部署作業→新版本」，不要按「新增部署作業」——後者會產生**新網址**，前端就對不上了。
4. 首次執行會要求授權 Drive 權限（因為要建資料夾存檔），照畫面允許。

## 部署後的行為

- Drive 我的雲端硬碟出現「**秘密客證據**」資料夾；每筆送出建一個子資料夾 `店別_yyyyMMdd_HHmmss`，附件依「類型_序號_原檔名」命名放入。
- Sheet 的「回收」分頁每筆一列，欄位含：基本資料、六段計時、加權總分／等級／食安違規、上菜紀錄、**證據資料夾連結**、**發票／出餐照／環境照／錄音各自的檔案連結**（多檔以換行分隔）、摘要與原始 JSON。
- 舊資料不受影響；新欄位結構從第一筆新送出開始（若「回收」分頁原本就有舊表頭，建議先另建分頁或讓程式寫到新分頁）。

## 驗收方式

手機開評鑑表 → 顧客體驗回饋 → 附一張測試照片 → 填店別「測試」→ 送出。
檢查：①Drive 出現 `測試_時間戳` 子資料夾且照片在內 ②Sheet 新增一列且發票連結欄有可點開的網址。驗完把該列與資料夾刪掉即可。

## 已知限制

- Apps Script POST 上限約 50MB；前端已在 25MB 就擋下並提示刪減，照片會先壓縮（長邊 1600px JPEG），一般 10 張內沒問題。
- 前端 `no-cors` 送出拿不到後端回應，所以「已送出」提示不代表後端成功——首次部署後務必跑一次上面的驗收。
